 # Dashboard de Celulares del año 2024

 Aplicación web interactiva desarrollada con **Streamlit**, **Pandas** y **Plotly** para explorar y visualizar especificaciones y métricas del mercado de teléfonos celulares durante el año 2024.

 ## Tecnologías utilizadas

* **Python**
* **Streamlit** (Desarrollo a la interfaz del tablero)
* **Pandas** (para el análisis y manipulación de datos)
* **Plotly** (Visualizaciones interactivas) 
* **Render** (Publicación y despliegue en la nube )

## Instalación y Uso Local

**Clonar el repositorio:**

   git clone https://github.com/javierglz11/dashboard-celulares-2024.git
